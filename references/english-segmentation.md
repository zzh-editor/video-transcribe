## 英文字幕断句策略

英文字幕保持单行，按原文标点和意群断句。用户提供的精校字幕仅用于学习断句风格，除非确认是同一段音频，否则不能借用其文字或时间轴。

- Groq 的有效语言为英文时（由 `--language en` 指定或 API 自动识别）使用 `scripts/english_segments.py`：即使原段很短，也在有可靠词时间的逗号、分号、冒号及句末标点后断开；标点留在前条。小数、缩写、缩合词中的符号不当作句界。
- 默认 `--max-line-length 60 --max-line-ms 6000`，对齐用户给出的单行样例长度。英文词间空格计入长度。长意群才补切短语边界，不为凑长度跨标点合并，也不把中文 8–18 字规则套在英文上。用户指定行长时，以用户要求为准。
- 保留单词、缩合词和正常词间空格；不运行中英混排的英文短语/残片合并步骤。
- `merge_english_fragments` 只合并时间相连、未以标点收尾的残句。依赖词收尾、后条小写承接/冠词开头或后条只有一个词时才考虑合并；句末/逗号标点、完整短应答和超过 0.4s 的停顿会阻止合并。
- 英文行数仍受最大行长限制；未合并短 cue 再补足可读时长。
- `audio_align.py` 按 0.2s RMS 包络收缩 Groq 词时间的静默边缘，阈值为噪声底 +10dB，首尾各留 0.25s；依赖 numpy。
- 若有字幕被收缩，校准记录写入 `<输出srt>.align.json`；失败时保留原始词时间并告警。
- 英文 cleanup 跳过 `dense_text`、`sparse_text`、`no_speech_metrics` 三条中文密度启发式，保留黑名单和重复环检测，避免误删快速语速内容。
- `timing_review` 标记须保留到 words sidecar；缺词或错序时不按字符比例伪造时间。
- 固定同一份 API 响应做断句回归，避免不同转写结果混入比较；不要把原始响应放入最终字幕目录。
