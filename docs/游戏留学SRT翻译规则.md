# SRT 字幕翻译规则（游戏留学 · 英译中）

方向：非中文（多为英文）→ 简体中文。中文优先，术语首次出现括注英文。仅此方向可用；中译英请看姊妹文件 `游戏留学SRT翻译规则_中译英.md`。

面向游戏美术 / 3D 制作 / 绑定（Rigging）/ 技术美术 / 游戏留学申请类英文视频，忠实传达原意，不重写、不升华。本文件是翻译的唯一规范，SKILL.md 不再重复细则。

---

## 〇 硬约束（最高优先级，违反即失败）

- **序号与时间轴** `HH:MM:SS,mmm --> HH:MM:SS,mmm` 原样保留，一字不改；只替换文本行。
- **条目数严格一致**：输入多少条就输出多少条，序号一一对应。禁止合并（多条塞进一条）或拆分（一条拆成多条）。
- **单条严格单行**：一条内不换行；每行 ≤18 个中文字符，超出通过精简措辞收窄。
- **不留空字幕**：原文仅为语气词/口癖（`um`/`you know`/`like`）时给最简自然中文或在不丢信息前提下省略，不得留空行。
- 纯文本，不加 Markdown；输入已有 `<i>` 等标签原样保留；输出 UTF-8。

## 一 跨条组织（核心规则）

英文常把一句长句切到连续多条。**条目数与时间轴是硬约束，各条内的词序不是**：

- 连续几条构成完整意思时，按**中文语序**在几条之间分配内容：允许调换顺序、允许倒装，不必逐条死守英文词序。
- 允许为语句通顺微调措辞。禁止增删信息、禁止改变逻辑、禁止动时间轴、禁止增减条数。
- 每条单独显示尽量自足通顺，连续几条合起来整体连贯；避免孤立短语残肢。

## 二 术语（中文优先，首次括注英文）

- **中文优先**：留学术语首次出现的那条给中文并括注英文，如 `作品集（Portfolio）`、`评改（Critique）`、`美术测试（Art Test）`、`录取（Offer）`、`管线（Pipeline）`；后续只用中文。括注 `()` 不受去标点限制。
- **软件/引擎/工具**：有通用中文名用中文并括注英文（`虚幻引擎（Unreal Engine 5）`）；业界直接用英文的不音译（`Maya`、`Hypershade`、`PySide6`、`PureRef`、`Perforce`、`Claude`）。代码/命令/路径原样保留不改大小写。
- **修正 ASR 误识别**：仅在有把握时修正（`make→Maya`、`py side 6→PySide6`、`Owatch→Overwatch`、`R Center→Art Center`），拿不准就保守保留原文。
- **院校名**：有通用中文名的首现括注（`谢尔丹学院（Sheridan）`、`萨凡纳艺术与设计学院（SCAD）`），无通用译名保留英文。
- 标题有官方译名加书名号（`《守望先锋》`），无官方译名保留原文；引擎/工具/公司/工作室名不加书名号。全片术语统一。

## 三 语言（适配中文字幕节奏）

- 简洁口语化，短顺、一眼可读，避免书面长句。语序按中文习惯调整（被动、从句嵌套转自然中文）。
- **口癖可删**（`um`/`uh`/`you know`/`like`/`kind of`），承载信息或态度时保留。
- **中西文混排**：CJK 与拉丁字母、数字间加空格（`用 Maya 做绑定`、`Python 3.9`）；代码、路径、URL、公式内部不加空格。
- 数字按中文习惯书写；度量首次出现可换算（`6 英寸≈15 厘米`）；版本号、分辨率、货币保持原值。
- **去标点**：句末标点移除；书名号《》、术语括注 `()` 例外。

## 四 输出

- 输出完整 .srt：全部序号、时间轴、中文译文，结构与输入一一对应。
- 只输出字幕本身，不加前言、总结或元语言。

## 附 自检清单

- [ ] 条数与序号 = 输入，时间轴原样，无合并/拆分
- [ ] 单条严格单行，每行 ≤18 中文字符
- [ ] 首现术语已中文+英文括注，后续统一；软件/院校/代码写法官方
- [ ] 跨条重排后连续几条顺，无残肢
- [ ] 去标点已执行（书名号、括注除外）
