# 本地音视频转 SRT

把电脑里的音频或视频整理成可编辑字幕。转录开始前，Agent 客户端会先问清语言、字幕版本、断句复核、润色和转录方式；你已经说过的要求不会再问。这个技能只处理本地文件，不下载 URL 中的媒体。

## 转录一段音视频

在 Agent 客户端里附上文件，直接说要什么字幕：

```text
把这个视频转成简体中文字幕，保留专业术语。
```

按任务补问的内容包括：

- 原音语言和字幕版本：原文、翻译或双语；翻译/双语时再问目标语言，双语还会问上下排列顺序。
- 是否做语义断句复核。开启后会检查小句边界和被识别器切开的相邻短句。
- 是否润色字幕。开启后再确认中英文空格、领域策略和术语括注；修改会单独显示，等你确认后才写入。
- 使用本地模型还是 Groq。使用 Groq 时，Agent 会在需要时让你安全提供 API Key；不要把密钥发在普通对话或命令里。

处理顺序是“转录与自动断句 → 可选语义复核 → 可选润色或翻译 → 输出字幕”。润色和翻译互相独立，不会因为转录请求自动翻译，也不会把未经确认的润色直接写入文件。

## 翻译已有 SRT

只有你明确要求“翻译”或“重写”时才进入翻译流程。已有 SRT 不会重新转录或自动润色；没有指定字幕排列方式时，Agent 会询问纯译文或双语排版。

```text
把这份英文 SRT 翻译成简体中文，中文在上、英文在下。
```

翻译时保留原有编号、条目数和时间轴。术语验证与翻译方向按字幕语言处理。

## 输出与竖屏字幕

普通 SRT 保存在输入文件旁边，原音视频和原字幕不覆盖。文件名会带上输出语言；确认润色后会加 `_Enhance`，例如 `lecture_zh_Enhance.srt`。

输出完成后，Agent 会询问是否保留临时文件。你也可以在这一步选择另做 9:16 竖屏版，例如 `lecture_zh_竖屏.srt`：竖屏字幕单独保存，按语义缩短行长并重排时间，不改字幕文字；校验通过后才清理临时文件。

## 常用说法

- “转录这个音频，输出中英双语，英文在上。”
- “只生成原文字幕，不做语义复核和润色。”
- “把这份 SRT 翻译成英文，不要重新转录。”
- “输出竖屏字幕后再清理临时文件。”

润色由 [Srt-Enhancer](https://github.com/zzh-editor/Srt-Enhancer) 提供。若 Agent 客户端无法加载该技能，会先征求你是否安装；拒绝或安装失败时，转录仍以原始字幕继续。
